# skills

A collection of useful skills for Copilot CLI and beyond.

## Collections

| Directory | Description |
|---|---|
| [`copilot-cli/`](./copilot-cli) | Skills for Copilot CLI power users |

## Install

### Full collection

```bash
# All copilot-cli skills
npx skill add pranay-gz/skills/copilot-cli
```

### Individual skills

```bash
# Launch a parallel Copilot session in a tmux window
npx skill add pranay-gz/skills/copilot-cli/copilot-tmux

# Measure token cost of any operation
npx skill add pranay-gz/skills/copilot-cli/copilot-context-diff
```

## Skills

### copilot-cli

| Skill | Description |
|---|---|
| `copilot-tmux` | Launch a full Copilot CLI session in a tmux window with skills, MCP tools, and agents intact |
| `copilot-context-diff` | Measure how many tokens any operation adds to the context window |
